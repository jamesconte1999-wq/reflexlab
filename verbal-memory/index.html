Verbal Memory Test

Words appear one at a time. Has this one shown up before? SEEN or NEW - three lives, no time limit.

How the verbal memory test works

Every word that appears joins a growing pool. When a word comes up, decide whether it already appeared this run (SEEN) or is brand new (NEW). Each correct answer scores a point; each mistake costs one of your three lives. The longer you last, the bigger the pool - and the trickier the judgment calls.

Recognition beats recall

You never have to reproduce a single word here, only recognize it, and human recognition memory is enormous - studies have shown people reliably recognizing thousands of images days later. That is why verbal memory scores dwarf digit-span scores. The failure mode is not forgetting; it is hesitating. Keyboard players can use S and N to stay in rhythm.

What does this test measure?

Recognition memory for words - keeping a growing pool of items tagged as familiar. You do not reproduce the words, just recognize them, so scores climb far higher than digit tests.

What is a good score?

Around 30-35 words is typical. Passing 80 is roughly top 10%, and runs in the hundreds happen when players find a rhythm and trust their first instinct.

Any strategy tips?

Trust your gut - familiarity judgments are fast and surprisingly accurate. Second-guessing is where most lives are lost.
