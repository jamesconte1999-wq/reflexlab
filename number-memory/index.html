Number Memory Test

A number appears for a few seconds, then vanishes. Type it back. One more digit every level.

How the number memory test works

Level one shows a single digit; every level after that adds one more. The number stays on screen a little longer as it grows, then disappears and you type what you saw. The run ends on your first mistake, and we show exactly which digits you got right so you can see where your memory slipped.

The "magic number seven"

Short-term memory famously holds about seven items, plus or minus two. To go beyond it, chunk digits into groups - remember 8-5-2-9-1-4-7-3 as 85, 29, 147, 3 and you are only holding four things. Memory athletes take this further by turning chunks into images, which is how world records reach hundreds of digits.

Why can most people only remember 7 digits?

Classic research found short-term memory holds about 7 plus or minus 2 items - it is why phone numbers were designed to be 7 digits. Beating it requires chunking.

How do memory athletes remember hundreds of digits?

They convert digits into images using systems like the Major system or PAO, then place those images along a memorized route. The digits become a story instead of raw data.

What is a good score?

Average is 7 digits. Reaching 10-11 puts you in roughly the top 10%, and 13+ without a mnemonic technique is remarkable.
